5. TRAP 信号说明
============================================================

⚠ 为什么会出现 TRAP？

后综合网表仿真的限制：
1. 网表是门级描述，内存被综合成寄存器/锁存器
2. 无法通过 $readmemh 或层次路径访问内部存储
3. 内存初始值为 X 或 0，CPU 执行非法指令
4. RISC-V 检测到非法指令触发 TRAP

✓ 这是正常行为！

TRAP 信号的出现证明了：
- CPU 异常检测机制工作正常
- TRAP 信号路径连接正确
- 异常处理逻辑已正确综合

如何验证程序功能？
- 使用 RTL 仿真（Chisel + Verilator）
- 使用 FPGA 原型验证
- 使用 JTAG 调试接口加载程序
