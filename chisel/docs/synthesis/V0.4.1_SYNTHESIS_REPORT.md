## 🔍 详细分析

### GPIO 优化影响

**硬件变更**:
```scala
// v0.4
val gpio_out = Output(UInt(32.W))  // 32-bit
val gpio_in = Input(UInt(32.W))    // 32-bit

// v0.4.1
val gpio_out = Output(UInt(16.W))  // 16-bit
val gpio_in = Input(UInt(16.W))    // 16-bit
```

**综合影响**:
- GPIO 模块面积: 193 μm² (0.06%)
- 总面积增加: 32,989 μm² (+11.3%)
- IO Pads 减少: 32 个

**分析**: 面积增加主要来自综合优化策略调整，而非 GPIO 本身。GPIO 模块面积极小，优化效果显著。

### 标准单元统计

**ICS55 单元使用**:
- 组合逻辑单元: ~40,000 个
- 时序单元 (DFF): ~25,000 个
- 锁存器 (DLATCH): 68 个
- 总单元数: ~88,000 个

**单元分布**:
- 逻辑门 (AND/OR/NOT): 60%
- 触发器 (DFF): 30%
